# eli12

Explain the topic below for a curious 12-year-old who has no prior knowledge of it. Produce the explanation as an HTML artifact with large, clear visuals and short sections.

- Start with the main idea in plain language.
- Use a concrete analogy or visual model when it makes the idea easier to understand.
- Introduce necessary technical terms one at a time and define each in simple language.
- Keep the tone respectful and age-appropriate rather than childish.
- Use short sentences, readable headings, and a small amount of text beside each visual.
- End with a concise recap of the key idea.
